# 🍔 BurgerFactory

## 📌 Présentation du projet

BurgerFactory est un site web interactif développé dans le cadre de ma formation **Bachelor 2 Informatique à l'EPSI**.

L'objectif de ce projet est de mettre en pratique les fondamentaux du JavaScript en créant une application permettant de gérer des ingrédients et de composer des burgers personnalisés.

Ce projet a été réalisé en binôme.

## 🛠️ Technologies utilisées

- **HTML5** — Structure du site web
- **CSS3** — Mise en page et design
- **JavaScript** — Interactivité et gestion des données
- **LocalStorage** — Sauvegarde des ingrédients dans le navigateur
- **AJAX / XMLHttpRequest** — Communication avec une API externe

## 🚀 Fonctionnalités

### 🏠 Accueil
- Diaporama automatique présentant différents burgers.
- Changement d'image toutes les 10 secondes.
- Affichage du nom du burger au clic sur l'image.

### 🥬 Création d'ingrédients
- Ajout d'ingrédients avec un nom et une quantité.
- Vérification des informations saisies.
- Sauvegarde des ingrédients avec LocalStorage.
- Mise à jour des listes d'ingrédients.
- Bouton permettant de réinitialiser les ingrédients créés.

### 🍔 Création de burgers
- Personnalisation du nom du burger.
- Sélection de trois ingrédients.
- Enregistrement des burgers dans un tableau JavaScript.
- Vérification et déduction des quantités d'ingrédients disponibles.

### 🌱 Qui sommes-nous ?
- Présentation du restaurant.
- Requête AJAX vers l'API de l'Agence BIO.
- Récupération et affichage d'informations concernant un producteur biologique et ses productions.

## 💻 Installation et utilisation

1. Télécharger ou cloner le dépôt GitHub.
2. Ouvrir le dossier dans Visual Studio Code.
3. Ouvrir le fichier `Burger.html` dans un navigateur, de préférence via Live Server.
4. Naviguer entre les différentes rubriques pour utiliser les fonctionnalités.

Une connexion Internet est nécessaire pour récupérer les informations de l'API externe.
